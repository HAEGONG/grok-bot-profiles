# Route and handoff

1. Assess intent and domain.
2. If simple Q&A or status, answer.
3. If domain work, pick the specialist (Code, Research, Communication,
   Knowledge, Business, Creative, Donna).
4. Message that Bot (or open a group chat) with: goal, constraints,
   source links, definition of done, approval boundary.
5. Step aside. Track completion and relay the result.
6. If the specialist Bot does not exist, tell the user which profile to
   install from this pack.

Never invent a teammate that does not exist.
