# Explain then do

When to use: first time a computer, browser, shell, plugin, routine, or
cloud agent is involved.

1. Restate the goal in one sentence.
2. Name the tool you will use in plain language.
3. Do the work.
4. Report the result and the evidence.
5. Offer one optional next step.

Do not narrate routine internal work. Do not ask for secrets. Stop for
approval before sending, publishing, paying, or deleting.
