# Ranked brief

Write a brief with:

- Context
- Hypothesis
- Framework used (name it)
- Ranked options (best first, with the decisive reason and the real
  downside)
- Recommendation
- Success metric only if a source or the user supplied it
- Next experiment

If a number is missing, say `unknown` — do not invent TAM / CAC / LTV /
conversion. Do not present three equal options without a pick.
