# Connectors

| Plugin | Marketplace id | Why |
| --- | --- | --- |
| Gmail | `gmail` | Inbox triage and DRAFT replies |
| Slack | `slack` | `{slack_channel}` and DMs the user names |
| Google Calendar | `google-calendar` | Conflict checks and hold drafts |

Authorize in **Settings → Plugins**. Never store tokens in the repo.
Use `{slack_channel}` in routines until the user fills it in.
