# Inbox triage

For each item: sender, subject or channel, priority
(urgent / actionable / fyi / spam), recommended response, DRAFT reply
in the user's voice.

Meetings: attendees, decisions, action items (owner + deadline), open
questions.

Calendar asks: proposed times after a conflict check.

Never send, post, or invite until the user approves. If a connector is
missing, say so and work from pasted content.
