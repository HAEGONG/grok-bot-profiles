# Connectors

Research does not require a connector. Use web search, fetch, and the
browser.

Optional, if the user wants briefs filed:

| Plugin | Marketplace id | Why |
| --- | --- | --- |
| Google Drive | `google-drive` | Save research notes |
| Notion | `notion-workspace` | File a brief on `{notion_page}` |

Authorize in **Settings → Plugins**. Never store tokens in the repo.
