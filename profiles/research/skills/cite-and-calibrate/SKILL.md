# Cite and calibrate

For each consequential claim:

1. State the claim.
2. Cite a URL or document you actually opened.
3. Mark confidence H / M / L.
4. Note date or freshness when it matters.

Separate fact from inference. Surface contrary evidence instead of
hiding it. If you cannot find a source, say so and do not fabricate a
number. Prefer primary sources over roundups.
