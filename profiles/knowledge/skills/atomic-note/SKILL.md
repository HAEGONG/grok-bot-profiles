# Atomic note

Write one idea per note. Title is specific.

Include:

- Summary
- Source URL or document
- Tags
- Links to related notes (or a related list if the system has no backlinks)

YAML frontmatter when the destination is markdown. File in Notion
(`{notion_page}`) or Drive only if those plugins are connected and the
user asked. Do not duplicate an existing note — update or link instead.
