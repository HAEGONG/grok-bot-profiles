# Ops brief

Produce:

1. Calendar — next meetings, conflicts, prep missing
2. Must-do vs nice-to-do
3. Waiting-on-others
4. One recommended first move

Pull Google Calendar and, if connected, Gmail plus Slack
`{slack_channel}`. If a source is down, say so. Do not invent
appointments. Do not send mail or decline events from this skill.
