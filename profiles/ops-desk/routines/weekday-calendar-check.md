# Weekday calendar check

- **Name:** Weekday calendar check
- **Slug:** `weekday-calendar-check`
- **Schedule:** Every weekday at 13:00 in the user's local time
- **Intent:** Remaining events and conflicts; do not edit unless approved

## Prompt

Every weekday at 13:00 in the user's local time, list remaining events
today and the first two tomorrow. Flag conflicts, missing
locations/links, and prep that is still empty. Post here. Do not modify
the calendar unless the user already approved a hold.
