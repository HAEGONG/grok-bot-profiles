# Connectors

| Plugin | Marketplace id | Why |
| --- | --- | --- |
| Google Calendar | `google-calendar` | Day plan, conflicts, holds |
| Gmail | `gmail` | Only what changes the day |
| Slack | `slack` | `{slack_channel}` pings |

Authorize in **Settings → Plugins**. Never store tokens in the repo.
Use `{slack_channel}` in routines until the user fills it in.
